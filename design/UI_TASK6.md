## 1. 修改记录页顶部工具栏语义错误

当前 `#screen-history` 的工具栏文字是「餐厅档案」（这是它上一个页面的名字），且没有页名。
修改记录是二级页，应显示：

- 左：返回箭头
- 中：「修改记录」
- 右：无（或留空占位，保持居中）

同时检查 `#screen-dishes`、`#screen-form` 的工具栏中间文字是否都是当前页面名：
- 菜品页应是「这家店的菜」（当前可能写的是餐厅名，改过来；餐厅名已经在大标题下方出现）
- 表单页应是「编辑餐厅」或「新增餐厅」——保留「餐厅档案」也行，但必须与下方的页面标题不矛盾；**统一改成「编辑餐厅」**

## 2. 详情页与编辑页的 10 格刻度条看不见

实测：`.tick-meter` 的盒子高度只有 **3px**，10 段几乎是一条实线，视觉上无法读出"9/10"。
改为：

- 高度从 3px 提到 **6px**，段与段 gap **3px**，总宽保持 120px（详情页）和 321px（编辑页，跟随表单宽度）
- 已填充段 `--accent`，未填充段改为 `--border`（浅色下 `rgba(0,0,0,0.08)` 太淡，改用 `--border-strong` 或 `#d8d8d2` 级别的实色），确保 10 段能数清
- 每段加 1px 圆角（`border-radius: 1px`），让分节感更明确
- 详情页刻度条下方补一行 9px 的刻度说明：`1.0 — 5.0`（两端对齐，`--tertiary`）

## 3. 评分口径必须写清楚

列表、详情、菜品三处的数字读者分不清是「我的评分」还是「综合评分」。统一处理：

- **列表页列头**：已写「评分」→ 改为「我的评分」（宁可窄一点，45px 列宽够放）
- **详情页**：大号 `4.3 / 5.0` 旁边加 9px 小字「我的评分」（不要只写「评分」）
- **菜品行**：评分前不加字，但菜品页的脚注保留「评分只代表自己的口味，满分 5.0」
- **编辑页**：标签已经是「我的评分」，保持

## 4. 滑杆精度可用性

0.1 精度只靠滑杆难精确操作。在滑杆两侧各加一个减/加按钮：

- 左侧 `−`、右侧 `+`，各 36×36px，边框 1px `--border`，圆角 4px
- 每次点击步进 **0.1**，同步更新读数和刻度条
- 按钮在读数到达 1.0 / 5.0 时置灰（`disabled`）
- 用 JS 实现，点击后 `input[type=range].value` 同步改变并触发联动

## 5. 菜品删除的确认

菜品展开编辑态里的「删除这道菜」：
- 点击后不要直接删，先把两个操作按钮（保存 / 删除）替换成一行确认条：`确定删除「麻婆豆腐」？` + 「取消」「删除」
- 确认条用 `--danger` 色的文字，静态画板里点「删除」可以只把该行变灰并标「已删除」示意，不需要真的移除
- 用 JS 实现切换
