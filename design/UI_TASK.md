# 任务：为「食记」Android App 重新做一套高保真 UI 设计（HTML 原型，三方向）

## 背景

产品叫 **食记**，个人餐厅探店记录 App。原生 Android（Kotlin + Compose + Material 3），
**完全不支持图片/照片/头像**（不接对象存储、没有上传入口），界面只有文字、数字、图标、色块。

之前的草案叫「石墨菜单」：纸白底 + 墨黑字 + 柠檬黄点缀 + 8dp 圆角小卡片。用户评价是
「看起来稍好，但还是不好看」——问题不是配色，是**整体像后台 CRUD 模板**：全是同一种大圆角
细边框卡片、字号层级平、灰色对比度不足、底部 tab 只有文字没有图标、假数据文案不自然、
星级色过亮抢注意力。

所以这次要**重做视觉语言**，不是微调配色。

## 你要产出的东西

一次性产出 **3 个视觉方向**，每个方向一套完整的移动端原型页面，全部写进
`/root/dining_log/design/proto/` 目录：

```
/root/dining_log/design/proto/
  d1-<slug>.html        方向 1 原型（单个自包含 HTML）
  d2-<slug>.html        方向 2
  d3-<slug>.html        方向 3
  DIRECTIONS.md         三方向说明 + 每个方向的完整 design token
```

### 每个 HTML 必须是「多屏画板」

一个 HTML 里横向/网格排列 **5 个 393×852 屏幕**（一个方向 = 5 屏），页面本身可以滚动画廊。
屏幕必须是**真实内容、真实中文文案**，不是线框图。5 屏固定为：

1. **餐厅列表**（首页）：标题、搜索入口、筛选芯片、8–10 家餐厅的列表、底部 tab bar
2. **餐厅详情**：店名、菜系/类型、评分、地址、评价长文、笔记、菜品入口、到店记录入口
3. **菜品库**（某餐厅）：8 道菜，每道有评分和短评
4. **修改记录 + 字段级 diff 详情**：列表里能看到「3 天前 评分 4→5」，点开是一屏 diff（原值划线 / 新值高亮，带时间戳）
5. **新增/编辑餐厅**：表单，含评分控件（未评分 / 1–5）、地址、类型选择、草稿提示与保存按钮

**另外每个方向必须再出一个 dark 变体**：同一批 5 屏，在画廊里用页面顶部的 `浅色/深色` 开关切换（纯 CSS 变量 + JS class 即可，不用重画一套 HTML）。深色是硬要求，用户手机常年深色模式。

## 三个方向（大方向由我定，你在每个方向里做扎实）

方向之间必须是**不同的版面构成和气质**，不能只是换颜色。

### D1「账簿 / Ledger」——暖纸 + 衬线 + 细分隔线
借 Anthropic Claude 的暖中性色（parchment / ivory / terracotta）与**编辑排版**逻辑，
但换成中文语义：像一本印出来的**菜单册 / 记账本**。

- 底色 parchment `#F6F3EC` 一类的暖纸白，卡片用 ivory `#FCFAF5`，几乎不用阴影
- 文字近黑但偏暖（如 `#1A1815`），二级文字必须过 AA（不要用 0.6 透明黑那种发虚的灰）
- **标题用中文衬线**（Google Fonts `Noto Serif SC`，weight 500/600），正文用 `Noto Sans SC`
- **不要卡片堆叠**：餐厅用「1px 发丝线分隔的行」排布，行内左对齐店名 + 右侧评分数字，
  第二行菜系 · 地址 · 菜数，第三行最近到店日期。像目录，不像 App 卡片列表
- 强调色只有一个：赤陶/辣椒红 `#B4523A` 这个族系，只用于主按钮、当前 tab、评分数字
- 圆角克制：4–8px，按钮 8px，不要 16px 大圆角
- 深色：近黑暖底 `#141312`，纸感消失但保留衬线标题和发丝线

### D2「Quiet Grid」——精确、克制、产品感
借 Linear + Notion 的精确度：极浅暖白、whisper 边框、紧凑信息、等宽数字。

- 底 `#FBFBFA`，面 `#FFFFFF`，边框 `rgba(0,0,0,0.08)`，1px
- 唯一强调色：深松绿 `#2F6B4F`（只做 CTA、当前 tab、评分徽章）
- 字体：`Noto Sans SC` + `IBM Plex Mono`/`JetBrains Mono` 只用于日期、评分、计数
  （数字等宽对齐，列表右列数字不跳动）
- 排版紧凑：行高 1.5，列表项 72–80px 高，字号 15/13/11 三档，**小字不用淡灰**（`#6B6A66` 起）
- tab bar 必须是**图标 + 文字**，选中态有实心图标 + 强调色 + 顶部指示
- 评分不是五颗大星星：用「4.5」数字 + 一条 3px 的小进度条或一个小方块组，绝不抢标题
- 深色：`#0F0F0E` 底、`#191918` 面、边框 `rgba(255,255,255,0.10)`、强调色提亮到 `#6FBF95`

### D3「招牌 / Signboard」——大字、冲击力、菜单海报
像现代居酒屋/面馆的菜单招牌：米纸底、纯黑、一个字重很强的大标题、蛋黄/芥末色点缀。

- 底 `#F2EFE6`，墨黑 `#111111`，点缀 `#E8B325`（或更暗的芥末 `#C99A18`，不要荧光）
- 超大店名字号（40–56px，Noto Sans SC 900 或 Noto Serif SC 700），允许两行
- 列表不用卡片：一行一家，右侧一个大号评分数字（28px mono），中间一条极细的黑色分隔线
- 允许「无效装饰」为零：所有东西必须承载信息；靠字号对比和留白撑版面
- 底部 tab 用粗黑图标 + 文字，选中项下方一条 2px 黑线
- 深色：`#0B0B0A` 底、白字、点缀降到 `#D9A21C`

## 硬性约束

1. **中文界面**，文案必须是自然的中文（`兰记川味小馆`、`陈记烧腊`、`老张牛肉面` 这种真实感），
   单位和量词正确（「5 道菜」「3 次到店」「2026-10-28」不要写成「5 菜」「10-28」）。
   不要出现 lorem ipsum、不要 emoji、不要占位方框。
2. **没有图片**：所有视觉靠排版、字号、发丝线、色块、图标。禁止 `<img>`、禁止渐变背景、
   禁止 glassmorphism、禁止给每张卡片配一个圆角图标方块（这是模板味的主要来源）。
3. 图标用内联 SVG（stroke 1.5–2，24px 视觉尺寸），不要图标字体。
4. 字体从 Google Fonts 引入（`Noto Sans SC` / `Noto Serif SC` / `JetBrains Mono` 按需），
   带本地 fallback 栈 `system-ui, "PingFang SC", "Microsoft YaHei", sans-serif`。
5. 每屏 393×852，四周留 24px 边距（D1 可 20px）。**每屏高度固定，内容溢出请裁剪**，
   不要出现 852px 之外的半截卡片——如果内容多，就减少条目数。
6. 对比度：正文/标题 ≥ 7:1，辅助文字 ≥ 4.5:1。写完后自己在 DIRECTIONS.md 里列出
   主要色对的计算对比度（用 Python 或手算并写出数值）。
7. 单文件自包含：CSS 内联 `<style>`，JS 内联 `<script>`，唯一外部依赖是 Google Fonts。
8. 不要写假数据里的大数字指标（「1,284 家」之类），数据要和场景一致。

## DIRECTIONS.md 要写什么

- 每个方向：气质一句话、它借的是哪个真实设计系统（给出品牌名和借用的具体规则）、
  完整 token 表（light + dark：bg/surface/ink/secondary/tertiary/border/accent/on-accent/danger，
  字体族与字号阶梯、间距、圆角、阴影、动效）
- 一个「三方向对比」表：哪个更适合长文阅读、哪个更适合大量条目、哪个最不像模板
- 明确写出你认为**哪一个最好**，以及为什么（要具体到版面决策，不要「更现代」这种空话）
